# 检测目录树形表格

基于 Vue 3 和 vxe-table 的树形目录表格，支持新增、删除、排序、层级调整、单元格编辑、分页和本地保存。

## 运行

```bash
npm install
npm run dev
npm test
npm run build
```

## 功能

- 一级目录和下级目录新增，批量选中后统一操作。
- 含下级目录删除时，可选择连同下级删除或将下级提升一级。
- 同级上移、下移，以及层级上移、下移。
- vxe-table 行拖拽排序，拖动后重新计算序号。
- 序号格式为 `1 / 1.1 / 1.1.1 / 2`，存入每行的 `no` 字段。
- 除序号和操作列外，其余列均可直接编辑。
- 负责人、完成时间和标准器支持批量设置。
- 数据以先序一维数组保存到 `localStorage`，刷新后恢复。
- 当前页选择与跨页保留选择均可用于批量操作。

## 数据说明

存储结构：

```json
{
  "version": 1,
  "page": 1,
  "pageSize": 10,
  "rows": [
    {
      "id": "dir_a",
      "parentId": null,
      "no": "1",
      "name": "被测对象概述",
      "opType": "文字编辑",
      "domain": "通用",
      "owner": "张工",
      "dueDate": "2026-11-10",
      "standard": "",
      "remark": "项目总体说明"
    }
  ]
}
```

数组按树的前序排列，父节点一定位于子节点之前。结构变化后统一重建树、扁平化并重算序号。

## 说明

- 表格使用 vxe-table 原生行拖拽排序。分页后只支持当前页内拖动。
- 层级调整也可通过操作列按钮完成，不受分页影响。
- 单元测试位于 `src/utils/*.spec.js`。
