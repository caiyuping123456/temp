# 树形目录表格 Demo（Vue 3 + Element Plus）

对应「前端 demo 需求」的完整实现：用表格维护树形目录，支持新增、删除、单元格编辑、层级调整、拖拽排序、自动生成 `1 / 1.1 / 1.1.1` 序号，并通过 `localStorage` 以**一维数组**持久化，刷新页面不丢数据。

## 技术栈

| 能力 | 选型 |
| --- | --- |
| 构建 | Vite 8 |
| 框架 | Vue 3（`<script setup>` 组合式 API） |
| 组件库 | Element Plus 2.14（中文 locale） |
| 树形表格 / 拖拽 | Element Plus `el-table` + 原生 HTML5 Drag & Drop（封装为 `useRowDrag`） |
| 单测 | Vitest |

> 需求文档推荐 vxe-table 的树形行拖拽；本实现改用 Element Plus 表格 + 自研拖拽 composable，避免额外引入一套表格组件，同时完整实现「拖拽排序 + 左右拖动改层级 + 缩进展示层级」的交互。

## 快速开始

```bash
cd demo/frontend
npm install
npm run dev       # http://localhost:5173
npm test          # 20 个树结构单测
npm run build      # 产物输出到 dist/
```

首次打开会自动写入一组示例目录；右上角「恢复示例数据」可随时重置。

## 功能与需求对照

| 需求 | 实现 |
| --- | --- |
| 表格展示树形目录（缩进 / 箭头） | 序号列展示 `1.2.1`，目录名称按层级缩进，存在子级的行显示箭头（只做标识，不折叠） |
| 序号格式 `1 / 1.1 / 1.1.1 / 2 ...` | 每次结构变化后统一调用 `renumber()` 重算，并单独存入每行的 `no` 字段 |
| 新增第一级 | 工具栏「新增第一级」，追加一行无父目录的行 |
| 新增下级（多选/必选） | 勾选一行或多行后点「新增下级」，新行插入父级子级的**最后一行** |
| 删除行（多选/必选） | 有子级时弹窗询问：「是」删除整棵子树；「否」仅删除当前行、子级整体提升一级；无子级直接删除 |
| 上移 / 下移 | 操作列按钮，同级首行不可上移、末行不可下移，违规时提示原因 |
| 向上 / 向下移一级 | 操作列按钮；最高层级不能上移一级，前面没有同级目录时不能下移一级 |
| 拖拽行的顺序 | 拖动行首手柄，落点显示插入线；左右移动指针可按 24px 一级调整层级，并实时提示目标层级 |
| 其余列可编辑 | 除「操作」「序号」外全部为文本框，直接编辑，失焦即保存 |
| 其余按钮弹窗写字段 | 「设置负责人 / 设置完成日期 / 设置标准器」三个批量按钮：选中行后弹窗输入，统一写入对应字段 |
| 分页 | 默认每页 10 条（可切 20 / 50），序号跨页连续，页码与每页条数一并持久化 |
| 刷新后保留数据 | 结构 + 单元格编辑通过 `watch(deep)` 自动写入 `localStorage`，`beforeunload` 兜底保存 |
| 一维数组存储 | 存储结构：`{ version, rows: [{ id, parentId, no, name, ... }], page, pageSize }`，`rows` 为**先序一维数组** |

## 数据结构

存储（也是运行时基准数据）是一维先序数组，父子关系由 `parentId` 表达：

```json
{
  "version": 1,
  "page": 1,
  "pageSize": 10,
  "rows": [
    { "id": "dir_a", "parentId": null, "no": "1", "name": "被测对象概述", "opType": "文字编辑", "domain": "/", "owner": "", "dueDate": "", "standard": "/", "remark": "" },
    { "id": "dir_b", "parentId": null, "no": "2", "name": "检测内容", "opType": "文字编辑", "domain": "/", "owner": "", "dueDate": "", "standard": "/", "remark": "" },
    { "id": "dir_c", "parentId": "dir_b", "no": "2.1", "name": "电气系统", "opType": "文字编辑", "domain": "/", "owner": "", "dueDate": "", "standard": "/", "remark": "" }
  ]
}
```

- 先序数组保证「父节点永远排在子节点之前」，渲染顺序、序号计算、分页 slice 都直接基于数组顺序；
- `no` 是派生字段但按要求单独存储，避免每次渲染重复计算；
- 结构变更时把数组临时转成嵌套树操作，再扁平化 + 重算序号，保证三者一致。

## 关键实现说明

1. **序号重算**：`renumber()` 按先序数组维护每层计数器，父节点序号 + 当前层计数拼出新序号；增删、同级移动、层级调整、拖拽后统一调用，避免各操作各算一套。
2. **拖拽层级换算**：拖动开始时记录指针 X 与源层级，拖动中按 `round(dx / 24)` 得到层级增量；落到目标行前后，`moveByDrag()` 会把「目标行 + 目标层级」换算成父节点与插入下标，并阻止拖进自己的子树。
3. **分页与层级**：分页按一维数组切片（默认 10 行），序号全局连续；新增行后自动跳到所在页。由于行被切到不同页，跨页拖拽不支持（同页拖拽与所有按钮操作不受影响）。
4. **持久化**：`watch(rows, { deep: true })` 覆盖单元格直接编辑；结构操作替换数组同样触发。写入前有 180ms 防抖，页面卸载时强制 flush。
5. **性能**：表格只渲染当前页数据；树操作均为 O(n)（`buildTree` 一次遍历 + 扁平化一次遍历），几百行规模无压力。

## 已知取舍

- 不实现行折叠：需求明确「有箭头表示有下级，不需要做折叠展开」，因此始终展开全部层级。
- 未接入后端接口：需求允许使用浏览器现有 API 存储，故采用 `localStorage`；如需切换到服务端，只需替换 `utils/storage.js` 的读写实现。
- 序号列只读、操作列只读；其余列均为纯文本输入，未做日期选择器（需求要求文本框）。
- 必填校验、撤销/重做不在本次需求范围内。
