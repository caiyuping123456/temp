      使用说明

      内容区域

      标识要成对写，名称只能用字母、数字和下划线，区分大小写。

      ${chapter1-start}
需要截取的内容
${chapter1-end}

      插入位置

      主文档里放 ${merge-point}；没有这个标记时，内容追加到文末。${toc} 用于指定目录位置。

      目录页码

      目录是 Word 域，页码不会在服务端固定。打开合并结果后按 Ctrl + A，再按 F9 更新。

      临时文件默认保留 2 小时。
