Word 文档合并

按 ${tag-start} / ${tag-end} 截取副文档内容，合并到主文档并生成目录

Spring Boot + docx4j

      尚未上传副文档

      标记规则

      截取区域

      标识必须成对出现，名称支持字母、数字、下划线，区分大小写：

      ${chapter1-start}
这里是需要截取的内容，可包含表格、图片、特殊样式
${chapter1-end}

      插入位置

      主文档中可使用以下特殊标记：

      ${merge-point}  合并内容插入到该位置
${toc}          目录插入到该位置

未提供时：内容追加到文末，目录放在开头。

      目录与页码

      合并结果会写入 Word 原生 TOC 域。为了兼容纯 Java 环境，页码由 Word 更新域时计算： 打开文档后按 Ctrl + A 再按 F9， 或允许 Word 提示的“更新域”即可。

      临时文件保存在服务端 docx-merge 目录，默认 2 小时后自动清理。
