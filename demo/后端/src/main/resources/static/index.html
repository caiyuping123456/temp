文档合并

上传主文档和副文档，按标记提取内容后生成新的 DOCX 文件。

上传文件

主文档 1 个，副文档可多个

      尚未上传副文档

      标记说明

      内容区域

      标识需成对出现，名称支持字母、数字和下划线，区分大小写。

      ${chapter1-start}
需要截取的内容
${chapter1-end}

      插入位置

      主文档可使用以下标记。未提供时，内容追加到文末，目录放在开头。

      ${merge-point}
${toc}

      目录页码

      合并结果写入 Word 原生 TOC 域。打开文件后按 Ctrl + A 再按 F9 更新页码。

      临时文件默认保存在系统临时目录，2 小时后自动清理。
